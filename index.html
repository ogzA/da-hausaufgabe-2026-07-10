JavaScript - Aufgaben

Sektion I : Basics

Basics-Aufgabe: 1

Aufgabenstellung: Erstelle zwei globale Variablen: eine für deinen Vornamen und eine für dein Alter. Schreib eine Funktion printName(), die folgenden Satz in der Konsole ausgibt: "Hallo, ich heiße [Name] und bin [Alter] Jahre alt." Teste die Funktion, indem du sie im Script aufrufst.

Basics-Aufgabe: 2

Aufgabenstellung: Schreibe eine Funktion getTrafficLightStatus(color). Der Funktion soll als Argument eine der Farben "green", "yellow" oder "red" als String übergeben werden. Je nach Farbe, soll die Funktion folgenden Wert zurückgeben:

  • AUFRUF: getTrafficLightStatus("green") ==> RÜCKGABEWERT: "Du darst gehen!"
  • AUFRUF: getTrafficLightStatus("yellow") ==> RÜCKGABEWERT: "Achtung!"
  • AUFRUF: getTrafficLightStatus("red") ==> RÜCKGABEWERT: "Du musst stehen bleiben!"
  • In allen anderen Fällen ==> RÜCKGABEWERT: "Die Ampel ist kaputt"
Teste die Funktion mit allen Varianten UND gib das Ergebnis jeweils in der Konsole aus.

Basics-Aufgabe: 3

Aufgabenstellung: Schreibe eine Funktion isEven(number), die true zurückgibt, wenn die number gerade ist, und false, wenn sie ungerade ist.
Teste die Funktion mit unterschiedlichen Test-Szenarien => Mit den Zahlen 4 und 7 UND gib das Ergebnis jeweils in der Konsole aus.

Hinweis: Mit dem %-Operator (Modulo) kannst du den Rest einer Division berechnen.
4 % 2 ergibt 0 => 4 ist daher gerade
9 % 2 ergibt 1 => 9 ist daher ungerade

Basics-Aufgabe: 4

Aufgabenstellung: Schreibe eine Funktion isAllowedToEnter(age, hasID), die true zurückgibt, wenn jemand 18 oder älter ist UND einen Ausweis dabei hat. In allen anderen Fällen soll false zurückgegeben werden.
Teste die Funktion mit unterschiedlichen Test-Szenarien => "20, true", "20, false" und "16, true" UND gib das Ergebnis jeweils in der Konsole aus.

Basics-Aufgabe: 5

Aufgabenstellung: Schreibe eine Funktion isValidEmail(email), die prüft ob eine E-Mail-Adresse das @-Zeichen enthält. Gibt true zurück wenn ja, false wenn nein.

Hinweis: Suche nach einer Dokumentation der String Methode .includes (z.B. bei W3Scools)

Sektion II : DOM-Manipulation

DOM-Aufgabe: 1

Aufgabenstellung: Erstelle im div mit der id dom-excersice-1

  • Ein Eingabefeld für den Vornamen
  • Ein Eingabefeld für das Alter
  • Ein Button "ok"
  • Ein leeres p-Tag mit der id dom-excersice-1-result
Wenn der Button "ok" geklickt wird, soll in dem p-Tag mit der id dom-excersice-1-result der Satz "Hallo, ich heiße [Name] und bin [Alter] Jahre alt." angezeigt werden. Für Name und Alter sollen die aktuellen Values der Eingabefelder genutzt werden

Hinweis: Du kannst die Funktion printName() aus der Aufgabe "Basics-Aufgabe: 1" nutzen/anpassen ODER eine neue Funktion schreiben.

Taschenrechner

Aufgabenstellung: Erstelle einen simplen Taschenrechner. Nutze dafür die gegeben Buttons. Folgende Punkte sind zu erledigen:

  • Erstelle eine globale Variable number1
  • Erstelle eine globale Variable number2
  • Erstelle eine globale Variable operator
  • Erstelle eine Funktion setNumberOne(number)
  • Erstelle eine Funktion setNumberTwo(number)
  • Erstelle eine Funktion setOperator(newOperator)
  • Erstelle eine Funktion getResult()
  • Wenn die Funktion setNumberOne aufgerufen wird (z.B. setNumberOne(9)) , soll das übergebene Argument als neuer Wert für die Variable number1 gesetzt werden UND im span-Tag mit der ID selected-number1 angezeigt werden.
  • Wenn die Funktion setNumberTwo aufgerufen wird (z.B. setNumberTwo(9)) , soll das übergebene Argument als neuer Wert für die Variable number2 gesetzt werden UND im span-Tag mit der ID selected-number2 angezeigt werden.
  • Wenn die Funktion setOperator aufgerufen wird (z.B. setOperator("+")) , soll das übergebene Argument als neuer Wert für die Variable operator gesetzt werden UND im span-Tag mit der ID selected-operation angezeigt werden.
  • Wenn die Funktion getResult aufgerufen wird, soll das Ergebnis mit den aktuell gesetzten Werten errechnet werden UND im span-Tag mit der ID calculator-result angezeigt werden.

Hinweis 1: Die jeweiligen Funktionsaufrufe sind in den Buttons schon hinterlegt.
